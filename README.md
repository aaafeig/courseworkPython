# Трекер по вакансиям на сайте HeadHunter.ru

***

## Описание:

Трекер позволяет *отслеживать выбранные вакансии*, *добавлять*, *редактировать* и *удалять* свои вакансии.

***

### Документация

#### Активировать виртуальное окружение

```bash
poetry self add poetry-plugin-shell
poetry shell
```

#### Установка зависимостей

```bash
poetry install
```
***
### Описание классов 

**HH** - api от Headhunter, который принимает ключевое слово и сохраняет в файл данный в формате json

**Vacancy** - класс для работы с вакансиями: изменением и созданием

**ShowVacancies** - класс для работы с json файлом, в который записывал данные класс HH.

****

##### Описание Vacancy


*Инициализация*

Передается название вакансии типа **str**, зарплата типа **int**, валюта типа **str** и описание вакансии типа **str**.

*Методы*

**Гетеры** и **Сеттеры**, метод **str**.

****


##### Описание ShowVacancies

*Инициализация*

Передается путь к json файлу типа **str**

*Методы*

**show_vacancies()** - Выводит в консоль информацию обо всех вакансиях(название, зарплату, описание)

**search_vacancies()** - Принимает на вход ключевые слова и ищет их в описаниях вакансий. Потом выводит информацию в консоль

**top_n()** - принимает число типа int и выводит вакансии с лучшими зарплатами, в том количество сколько передалось в метод.

**my_vacancies()** - выводит в консоль все вакансии созданные пользователем.

**edit_vacancy()** - принимает 3 аргумента и меняет информацию о вакансии в выбранном сегменте

**delete_vacancy()** - удаляет вакансию по выбранному id
